# README guidance

Write READMEs for both humans and agents. Include only what readers need to understand or use the project. Omit details that are already clear from the surrounding text or examples.

If you change any README, show the human reviewer the README diff and call out any documented behavior, command, or prerequisite you removed or changed. Ask them to read the diff and explicitly confirm before merge that they read and approve the README changes.

# Direct and server modes

Keep the behavior of direct and server modes consistent wherever possible. If they need to differ, explain the reason.
